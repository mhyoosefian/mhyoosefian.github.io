<div class="preview-note"><strong>This page is under construction.</strong> There are numerous <em>variants</em> of the Kalman filter in the literature, each designed with a purpose: some for nonlinear systems (e.g., EKF), some for non-Gaussian noise (e.g., MCKF). The Kalman Filter Encyclopedia is a project in which we collect the well-known Kalman filter variants, give a summary of them, teach how to implement them, and help the user to pick the one(s) relavant to their application.</div>
